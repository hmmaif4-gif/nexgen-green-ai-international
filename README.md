# NEXGEN GREEN AI

Premium AI assistant frontend with Netlify-ready serverless backend.

## Run locally

```bash
npm install
npm run dev
```

Then open:

- http://localhost:8888

If you want to use real Gemini generation, add this to your environment:

```bash
GEMINI_API_KEY=your_api_key_here
```

## Features

- Modern ChatGPT/Gemini-inspired UI
- Bengali + English support
- Dark/light theme toggle
- Rich markdown response formatting
- Netlify function backend
- Copy and regenerate actions
- Local conversation storage
